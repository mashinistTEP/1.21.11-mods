# GOD EQUIPMENT

Один мод для Fabric (Minecraft **1.21.11**, Java 21), который:

- полностью переписывает `/give` — свой синтаксис зачарований
  `{ench: имя_уровень, ...}`, названия можно писать по-русски или по-английски;
- добавляет команду `/ench <цели> <имя_уровень, ...>` — зачаровывает предмет
  в руке тем же синтаксисом;
- через `config/godequipment.json` включает три доп. поведения: снятие
  лимита уровня зачарования, разрешение несовместимых зачарований вместе,
  разрешение любых зачарований на любых предметах.

Раньше это было 5 отдельных модов-аддонов — теперь всё в одном `.jar`,
а переключатели вынесены в конфиг, чтобы не нужно было ставить/убирать
разные файлы ради одной настройки.

## Синтаксис

```
/give <цели> <предмет>[{ench: имя_уровень, имя_уровень, ...}] [количество]
/ench <цели> <имя_уровень, имя_уровень, ...>
```

```
/give @s netherite_sword{ench: sharpness_5, looting_3} 1
/give @s Незеритовый_меч{ench: добыча_5, острота_10}
/ench @s острота_10, добыча_5
```

## config/godequipment.json

Создаётся автоматически при первом запуске (папка `config/` в вашем
инстансе/сервере). По умолчанию всё `false` — мод ведёт себя максимально
"по-ванильному" (уровни обрезаются до обычного максимума, несовместимые
чары и предметы не по теме — отфильтровываются). Чтобы что-то включить,
поставьте `true` и перезапустите игру/сервер:

```json
{
  "unlimitedEnchantLevel": false,
  "anyEnchantCombo": false,
  "anyItemAnyEnchant": false
}
```
